<b>NeoAxis Engine</b> is a versatile game engine designed for creating video games and real-time apps. It is well-suited for developing various 3D and 2D projects, including computer games, simulators, and apps with rich graphics.

Website: <a href="https://www.neoaxis.com/">www.neoaxis.com</a>

Alternative website: <a href="https://www.neoaxis.cn/en/">www.neoaxis.cn/en/</a>

<h2>Building</h2>

How to compile for Windows:
<ul>
<li>Install Visual Studio 2026 Community or an equivalent IDE.</li>
<li>Use NeoAxis.Managed.sln with the Release-Windows-x64 configuration to compile the managed assemblies.</li>
<li>The native code is already precompiled.</li>
</ul>

More:
<ul>
<li>For information on building for other platforms, please check https://www.neoaxis.com/docs/html/Platforms.htm.</li>
<li>To compile project assemblies, you can use Visual Studio Code or another C# IDE. Use NeoAxis.ProjectOnly.AnyIDE.sln.</li>
</ul>

<h2>Programming tips</h2>
<ul>
<li>Set up the NeoAxis.Editor assembly as the startup project to run it with the debugger.</li>
<li>Add new code to the Project assembly by default. The source code of the Project assembly can be changed in the NeoAxis Editor.</li>
<li>Consider using the built-in editor C# scripting to create scene and GUI scripts. https://www.neoaxis.com/docs/html/Scripting_Overview.htm</li>
<li>Use the English code page for your project if possible.</li>
</ul>
